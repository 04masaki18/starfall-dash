# Changelog

All notable changes to STARFALL DASH are recorded here.

## v1.0.0 - 2026-08-08

Initial public release.

### Added

- One-screen meteor-dodging game built with HTML5 Canvas
- Keyboard controls with Arrow keys / A and D
- Mobile drag controls
- Survival score and persistent best score
- Near-miss bonus (`+25`)
- Difficulty scaling over time
- Title, game-over, new-best, and retry flows
- Generated sound effects using the Web Audio API
- Responsive browser presentation
- Automated game-core logic tests
- GitHub Pages public deployment
